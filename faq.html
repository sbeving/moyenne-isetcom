Account & Data

Your data is stored locally on your device using browser localStorage. This means:

  • Your data is 100% private
  • No data is sent to any server
  • Only you can access it
  • Stays even after closing browser

To backup your data:

  1. Open Developer Tools (F12)
  2. Go to Console tab
  3. Type: StorageManager.export()
  4. Copy the output and save to a file

To restore backup data:

  1. Open Developer Tools (F12)
  2. Go to Console tab
  3. Type: StorageManager.import(YOUR_DATA)
  4. Replace YOUR_DATA with your exported data

Your data will be lost! To avoid this:

  • Export your data regularly
  • Be careful when clearing cache
  • Use import function to restore from backup
  • Consider not clearing all site data

Each device has its own local storage. To sync:

  1. Export data from Device A
  2. Go to Device B
  3. Import the exported data
  4. Now both devices have the same data
